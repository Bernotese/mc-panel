# Teilprojekt 3b – panel (Aufgaben 9–12) – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das panel bekommt das Paket `internal/serverfiles`: Dateiliste, Editor (Lesen/Speichern), Verwalten (Ordner anlegen, Umbenennen, Löschen), Up- und Download als Stream ohne Puffer und Entpack-Jobs – alles nur über den unprivilegierten Dienst `mcpanel-files`. Während eines Entpack-Jobs startet der Server weder per Power-Aktion noch durch den Abgleich.

**Architecture:** `serverfiles.Handler` besitzt die zehn Routen aus V3/V4 der Übersicht. Jede Route lädt den Server (nicht eingerichtet → `404`), prüft den Pfad mit `filesapi.CleanPath`/`IsHidden` (verborgen → `404`), ruft den `filesapi.Client` und schreibt bei Änderungen und Downloads einen Audit-Eintrag. Upload und Download laufen als Stream: Das globale Limit `httpx.BodyLimitExcept(1 MiB, serverfiles.UnlimitedBody)` (Phase A) lässt die Upload-Route und – ab Aufgabe 10 – das Editor-Speichern aus; der Upload liest höchstens `Content-Length` Bytes, das Speichern begrenzt der Handler selbst auf `filesapi.MaxJSONBytes` (32 MiB). Lese- und Schreibfristen werden pro Vorgang über `http.ResponseController` gesetzt. Fürs Entpacken fragt der Handler den Ist-Zustand beim agent; `ExtractRunning` implementiert `servers.ExtractGate`, das `internal/servers` vor `power start/restart` und im Abgleich vor einem Start fragt.

**Tech Stack:** Go (Standardbibliothek, chi, sqlc/`store`), `http.ResponseController`, `regexp`. Keine neuen Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-10-11-mc-panel-files-design.md` (§5). Verträge V1, V3, V4, Global Constraints, Review Focus und Dateieigentum B2: `docs/superpowers/plans/2026-10-11-files-00-overview.md`.

## Entscheidungen innerhalb dieses Teilplans

1. **Body-Limit über `serverfiles.UnlimitedBody`:** Phase A liefert `httpx.BodyLimitExcept` und `UnlimitedBody` (nur Upload). Das Editor-Speichern braucht bis zu 32 MiB (`filesapi.MaxJSONBytes`, Phase-A-Abweichung 2), das globale 1-MiB-Limit würde jede Config über 1 MiB mit `413` ablehnen. Aufgabe 10 nimmt deshalb `PUT …/files/content` in `UnlimitedBody` auf, und `handleWrite` wickelt den Body selbst in `http.MaxBytesReader(w, r.Body, filesapi.MaxJSONBytes)` (schon ab Aufgabe 9, dort wirkungslos, weil das globale Limit kleiner ist). `httpx` und die Middleware-Kette in `cmd/panel` bleiben unverändert.
2. **Download flusht nach jedem Schreiben:** Sonst hielte der `bufio`-Puffer des `ResponseWriter` kleine Teile zurück, und der Stream-Test könnte „kein Puffern“ nicht belegen. `io.Copy` schreibt in 32-KiB-Blöcken; ein Flush pro Block kostet nichts Messbares.
3. **Verborgen = `404` auch beim Anlegen:** Wer `.rcon-cli.env` hochladen, anlegen oder als Rename-Ziel nennen will, bekommt `404 not_found` (wie in der Spec „jeder Zugriff“). Ein `400` würde verraten, dass der Name besonders ist.
4. **Wurzel nur für Liste und Download:** Lesen, Speichern, Hochladen, Anlegen, Umbenennen, Löschen und Entpacken mit `path = ""` sind `400 validation_failed`, bevor der Dienst gefragt wird (der Dienst lehnt sie ebenfalls ab, Spec §4).
5. **Restrisiko beim Entpacken:** Zwischen Zustandsprüfung und Job-Start kann ein Start durch einen anderen Nutzer liegen (Millisekunden). Danach greift die Sperre (`ExtractGate`). Das ist laut Spec §2 akzeptiert und steht in der Spec.
6. **`JobState`-Konstanten aus Phase A:** `filesapi.JobRunning`, `JobDone`, `JobFailed`.
7. **Audit beim Entpacken:** Der Dienst prüft das Archiv synchron (Phase A, Spec §4.2): ungültiges Archiv `400 invalid`, Ziel nicht leer `409 exists`, zu groß `413 too_large`, Platz `507` kommen als Fehler, erst danach `202` + Job. Wie bei allen anderen Datei-Aktionen wird **jeder Aufruf, der den Dienst erreicht** (also nach Pfad- und Zustandsprüfung), als `file.extract` mit `success` (bei `202`) bzw. `failure` (bei jedem Dienst-Fehler) auditiert. Begründung: Die übrigen Aktionen (`write`, `mkdir`, `upload` …) protokollieren ebenfalls abgelehnte Versuche, sobald der Dienst gefragt wurde (z. B. `409 file_exists` bei `mkdir`); ein abgelehntes Welt-Archiv ist genauso ein Änderungsversuch an den Daten. Nicht auditiert werden – wie überall – Ablehnungen davor (Pfad, Rechte, `409 instance_running`, agent nicht erreichbar).

// fakeFiles is an in-memory filesapi.Client. Calls are recorded in order ("list 1 plugins").
type fakeFiles struct {

	err      error  // returned by every call while set

	calls    []string
	list     filesapi.ListResponse
	read     filesapi.ReadResponse
	writeRes filesapi.WriteResponse
	writes   []filesapi.WriteRequest
	uploads  map[string][]byte
	// uploadHook, if set, consumes the upload body instead of io.ReadAll (stream tests).
	uploadHook func(body io.Reader) (int64, error)
	download   filesapi.Download
	job        *filesapi.Job
	extracts   []filesapi.ExtractRequest
}

func newFakeFiles() *fakeFiles { return &fakeFiles{uploads: map[string][]byte{}} }

func (f *fakeFiles) setErr(err error) { f.mu.Lock(); f.err = err; f.mu.Unlock() }

func (f *fakeFiles) setJob(j *filesapi.Job) { f.mu.Lock(); f.job = j; f.mu.Unlock() }

func (f *fakeFiles) setUploadHook(h func(io.Reader) (int64, error)) {
	f.mu.Lock()
	f.uploadHook = h
	f.mu.Unlock()
}

// takeCalls returns the recorded calls and forgets them.
func (f *fakeFiles) takeCalls() []string {
	f.mu.Lock()
	defer f.mu.Unlock()
	out := f.calls
	f.calls = nil
	return out
}

// begin records call; like the real client it fails with ErrUnavailable once ctx is done.
func (f *fakeFiles) begin(ctx context.Context, call string) error {
	f.mu.Lock()
	hook := f.onCall
	f.mu.Unlock()
	if hook != nil {
		hook()
	}
	f.mu.Lock()
	defer f.mu.Unlock()
	if err := ctx.Err(); err != nil {
		return fmt.Errorf("%w: %w", filesapi.ErrUnavailable, err)
	}
	if f.err != nil {
		return f.err
	}
	f.calls = append(f.calls, call)
	return nil

// loadServer returns the server of the {id} path parameter if it has an instance; it writes
// 404 itself for malformed ids, unknown servers and servers without instance (spec §5.1).
func (h *Handler) loadServer(w http.ResponseWriter, r *http.Request) (store.Server, bool) {
	ctx := r.Context()
	id, err := strconv.ParseInt(chi.URLParam(r, "id"), 10, 64)
	if err != nil || id <= 0 {
		writeServerNotFound(w, r)
		return store.Server{}, false
	}
	s, err := h.q.RbacGetServer(ctx, id)
	if errors.Is(err, sql.ErrNoRows) {
		writeServerNotFound(w, r)
		return store.Server{}, false
	}
	if err != nil {
		httpx.Internal(w, r, err)
		return store.Server{}, false
	}
	_, err = h.q.ServersGetInstance(ctx, id)
	if errors.Is(err, sql.ErrNoRows) {
		writeServerNotFound(w, r)
		return store.Server{}, false
	}
	if err != nil {
		httpx.Internal(w, r, err)
		return store.Server{}, false
	}
	return s, true
}

// cleanPath validates a path (spec §3.4); "" is the data directory. A hidden path is answered
// like a missing file. It writes the error itself.
func cleanPath(w http.ResponseWriter, r *http.Request, p string) (string, bool) {
	c, err := filesapi.CleanPath(p)
	if err != nil {
		writeValidation(w, r, "invalid path: "+err.Error())
		return "", false
	}
	if filesapi.IsHidden(c) {
		writeFileNotFound(w, r)
		return "", false
	}
	return c, true
}

// cleanItemPath is cleanPath for operations on one file or directory: the data directory
// itself is not allowed (decision 4).
func cleanItemPath(w http.ResponseWriter, r *http.Request, p string) (string, bool) {
	c, ok := cleanPath(w, r, p)
	if ok && c == "" {
		writeValidation(w, r, "the path must name a file or directory inside the data directory")
		return "", false
	}
	return c, ok
}

// writeFilesError maps a failed service call to the API error (table in the plan's constraints).
func (h *Handler) writeFilesError(w http.ResponseWriter, r *http.Request, err error) {
	switch {
	case r.Context().Err() != nil:
		// The client went away: nobody reads an answer, and it is not a server error.
		h.log.DebugContext(r.Context(), "file operation ended with the request", "err", err)
	case errors.Is(err, filesapi.ErrNotFound):
		writeFileNotFound(w, r)
	case errors.Is(err, filesapi.ErrExists):
		httpx.WriteError(w, r, http.StatusConflict, httpx.CodeFileExists, "the target already exists")
	case errors.Is(err, filesapi.ErrModified):
		httpx.WriteError(w, r, http.StatusConflict, httpx.CodeFileModified, "the file was changed since it was opened")
	case errors.Is(err, filesapi.ErrNotText):
		httpx.WriteError(w, r, http.StatusUnsupportedMediaType, httpx.CodeNotText, "the editor cannot open this file (too large or not text)")
	case errors.Is(err, filesapi.ErrNotRegular):
		httpx.WriteError(w, r, http.StatusBadRequest, httpx.CodeNotRegular, "not a regular file")
	case errors.Is(err, filesapi.ErrTooLarge):
		httpx.WriteError(w, r, http.StatusRequestEntityTooLarge, httpx.CodePayloadTooLarge, "the file is too large")
	case errors.Is(err, filesapi.ErrInsufficientStorage):
		httpx.WriteError(w, r, http.StatusInsufficientStorage, httpx.CodeInsufficientStorage, "not enough free disk space")
	case errors.Is(err, filesapi.ErrBusy):
		w.Header().Set("Retry-After", "5")
		httpx.WriteError(w, r, http.StatusTooManyRequests, httpx.CodeRateLimited, "the file service is busy, try again shortly")
	case errors.Is(err, filesapi.ErrInvalid):
		writeValidation(w, r, err.Error())
	case errors.Is(err, filesapi.ErrUnavailable), errors.Is(err, context.DeadlineExceeded):
		httpx.WriteError(w, r, http.StatusServiceUnavailable, httpx.CodeFilesUnavailable, "the file service is not reachable")
	default:
		httpx.Internal(w, r, err)
	}
}

		if n := len(e.rec.Actions()); n > 0 {

}

const maxUploadsPerUser = 2

// uploadSlots counts running uploads per user.
type uploadSlots struct {
	mu sync.Mutex
	n  map[int64]int
}

func newUploadSlots() *uploadSlots { return &uploadSlots{n: map[int64]int{}} }

// acquire takes a slot of userID; release must be called exactly once.
func (u *uploadSlots) acquire(userID int64) (release func(), ok bool) {
	u.mu.Lock()
	defer u.mu.Unlock()
	if u.n[userID] >= maxUploadsPerUser {
		return nil, false
	}
	u.n[userID]++
	var once sync.Once
	return func() {
		once.Do(func() {
			u.mu.Lock()
			defer u.mu.Unlock()
			if u.n[userID]--; u.n[userID] <= 0 {
				delete(u.n, userID)
			}
		})
	}, true
}

func ignoreUnsupported(err error) error {
	if errors.Is(err, http.ErrNotSupported) {
		return nil
	}
	return err
}

// deadlineReader sets a fresh read deadline before every read of the request body: the
// server's ReadTimeout only bounds silence, not the length of an upload.
type deadlineReader struct {
	r  io.Reader
	dl func() error
}

func (d *deadlineReader) Read(p []byte) (int, error) {
	if err := d.dl(); err != nil {
		return 0, err
	}
	return d.r.Read(p)
}

// deadlineWriter sets a fresh write deadline before every write and flushes after it, so the
// browser receives the download as it arrives (decision 2).
type deadlineWriter struct {
	w     io.Writer
	dl    func() error
	flush func() error
}

func (d *deadlineWriter) Write(p []byte) (int, error) {
	if err := d.dl(); err != nil {
		return 0, err
	}
	n, err := d.w.Write(p)
	if err != nil {
		return n, err
	}
	return n, d.flush()
}

// parseOverwrite reads the boolean overwrite query parameter (OpenAPI: true|false, missing =
// false); the files client sends it to the service as 0|1.
func parseOverwrite(v string) (bool, bool) {
	switch v {
	case "", "false":
		return false, true
	case "true":
		return true, true
	}
	return false, false
}

func (h *Handler) handleUpload(w http.ResponseWriter, r *http.Request) {
	ctx := r.Context()
	s, ok := h.loadServer(w, r)
	if !ok {
		return
	}
	q := r.URL.Query()
	p, ok := cleanItemPath(w, r, q.Get("path"))
	if !ok {
		return
	}
	overwrite, ok := parseOverwrite(q.Get("overwrite"))
	if !ok {
		writeValidation(w, r, "overwrite must be true or false")
		return
	}
	if r.ContentLength < 0 {
		writeValidation(w, r, "Content-Length is required")
		return
	}
	pr, _ := principal.From(ctx) // guaranteed by the rbac rule
	release, ok := h.uploads.acquire(pr.UserID)
	if !ok {
		w.Header().Set("Retry-After", "5")
		httpx.WriteError(w, r, http.StatusTooManyRequests, httpx.CodeRateLimited, "at most 2 uploads at a time, try again when one is done")
		return
	}
	defer release()
	rc := http.NewResponseController(w)
	body := &deadlineReader{
		r:  io.LimitReader(r.Body, r.ContentLength),
		dl: func() error { return ignoreUnsupported(rc.SetReadDeadline(h.ioClock.Now().Add(h.ioTimeout))) },
	}
	res, err := h.files.Upload(ctx, s.ID, p, overwrite, r.ContentLength, body)
	// The answer may come long after the WriteTimeout that started with the request.
	if dlErr := ignoreUnsupported(rc.SetWriteDeadline(h.ioClock.Now().Add(h.ioTimeout))); dlErr != nil {
		h.log.DebugContext(ctx, "set write deadline", "err", dlErr)
	}
	h.record(ctx, audit.ActionFileUpload, s.ID, result(err), map[string]any{"path": p, "size": r.ContentLength})
	if err != nil {
		h.writeFilesError(w, r, err)
		return
	}
	httpx.WriteJSON(w, http.StatusCreated, res)
}

func (h *Handler) handleDownload(w http.ResponseWriter, r *http.Request) {
	ctx := r.Context()
	s, ok := h.loadServer(w, r)
	if !ok {
		return
	}
	p, ok := cleanPath(w, r, r.URL.Query().Get("path")) // "" = the whole data directory as zip
	if !ok {
		return
	}
	d, err := h.files.Download(ctx, s.ID, p)
	if err != nil {
		h.record(ctx, audit.ActionFileDownload, s.ID, audit.ResultFailure, map[string]any{"path": p})
		h.writeFilesError(w, r, err)
		return
	}
	defer func() { _ = d.Body.Close() }()
	name := d.Name
	if name == "" {
		name = s.Name
	}
	hdr := w.Header()
	if d.IsDir {
		name += ".zip"
		hdr.Set("Content-Type", "application/zip")
	} else {
		hdr.Set("Content-Type", "application/octet-stream")
		if d.Size >= 0 {
			hdr.Set("Content-Length", strconv.FormatInt(d.Size, 10))
		}
	}
	hdr.Set("Content-Disposition", attachment(name))
	rc := http.NewResponseController(w)
	dw := &deadlineWriter{
		w:     w,
		dl:    func() error { return ignoreUnsupported(rc.SetWriteDeadline(h.ioClock.Now().Add(h.ioTimeout))) },
		flush: func() error { return ignoreUnsupported(rc.Flush()) },
	}
	res := audit.ResultSuccess
	if err := dw.dl(); err != nil {
		res = audit.ResultFailure
	} else {
		w.WriteHeader(http.StatusOK)
		if _, err := io.Copy(dw, d.Body); err != nil {
			res = audit.ResultFailure
			h.log.DebugContext(ctx, "download aborted", "server_id", s.ID, "path", p, "err", err)
		}
	}
	h.record(ctx, audit.ActionFileDownload, s.ID, res, map[string]any{"path": p})
}

// attachment returns a Content-Disposition value with an ASCII fallback name and the exact
// UTF-8 name (RFC 6266, RFC 5987).
func attachment(name string) string {
	var ascii strings.Builder
	for _, c := range name {
		if c < 0x20 || c > 0x7e || c == '"' || c == '\\' || c == ';' {
			ascii.WriteByte('_')
			continue
		}
		ascii.WriteRune(c)
	}
	return `attachment; filename="` + ascii.String() + `"; filename*=UTF-8''` + rfc5987(name)
}

func rfc5987(s string) string {
	const hex = "0123456789ABCDEF"
	var b strings.Builder
	for i := 0; i < len(s); i++ {
		c := s[i]
		if isAttrChar(c) {
			b.WriteByte(c)
			continue
		}
		b.WriteByte('%')
		b.WriteByte(hex[c>>4])
		b.WriteByte(hex[c&15])
	}
	return b.String()
}

func isAttrChar(c byte) bool {
	switch {
	case 'a' <= c && c <= 'z', 'A' <= c && c <= 'Z', '0' <= c && c <= '9':
		return true
	}
	return strings.IndexByte("!#$&+-.^_`|~", c) >= 0
}

package serverfiles

import (
	"context"
	"errors"
	"net/http"
	"time"

	"github.com/Bernotese/mc-panel/internal/agent/agentapi"
	"github.com/Bernotese/mc-panel/internal/audit"
	"github.com/Bernotese/mc-panel/internal/files/filesapi"
	"github.com/Bernotese/mc-panel/internal/httpx"
)

// gateTimeout bounds the job query of ExtractRunning: power actions and the reconcile loop
// must not hang on an unreachable service.
const gateTimeout = 2 * time.Second

type extractRequest struct {
	Path string `json:"path"`
	Dest string `json:"dest"`
}

// jobsJSON is the OpenAPI schema FileJobResponse.
type jobsJSON struct {
	Job *filesapi.Job `json:"job"`
}

var errRunning = errors.New("the server is running")

func (h *Handler) handleExtract(w http.ResponseWriter, r *http.Request) {
	ctx := r.Context()
	s, ok := h.loadServer(w, r)
	if !ok {
		return
	}
	var req extractRequest
	if !httpx.DecodeJSON(w, r, &req) {
		return
	}
	p, ok := cleanItemPath(w, r, req.Path)
	if !ok {
		return
	}
	dest, ok := cleanItemPath(w, r, req.Dest)
	if !ok {
		return
	}
	if err := h.checkStopped(ctx, s.ID); err != nil {
		h.writeStateError(w, r, err)
		return
	}
	job, err := h.files.Extract(context.WithoutCancel(ctx), filesapi.ExtractRequest{ID: s.ID, Path: p, Dest: dest})
	h.record(ctx, audit.ActionFileExtract, s.ID, result(err), map[string]any{"path": p, "dest": dest})
	if err != nil {
		h.writeFilesError(w, r, err)
		return
	}
	httpx.WriteJSON(w, http.StatusAccepted, job)
}

func (h *Handler) handleJobs(w http.ResponseWriter, r *http.Request) {
	s, ok := h.loadServer(w, r)
	if !ok {
		return
	}
	job, err := h.files.Job(r.Context(), s.ID)
	if err != nil {
		h.writeFilesError(w, r, err)
		return
	}
	httpx.WriteJSON(w, http.StatusOK, jobsJSON{Job: job})
}

// checkStopped asks the agent for the actual state (spec §5.1): only a server whose container
// is exited, created or missing – or that the agent does not list at all – and that the agent
// is not working on may be extracted into.
func (h *Handler) checkStopped(ctx context.Context, id int64) error {
	resp, err := h.inst.Instances(ctx)
	if err != nil {
		return err
	}
	if resp.Docker != agentapi.DockerOK {
		return agentapi.ErrDockerUnavailable
	}
	for _, st := range resp.Instances {
		if st.ID != id {
			continue
		}
		if st.Operation != agentapi.OpNone {
			return errRunning
		}
		switch st.State {
		case agentapi.StateExited, agentapi.StateCreated, agentapi.StateMissing:
			return nil
		}
		return errRunning
	}
	return nil
}

func (h *Handler) writeStateError(w http.ResponseWriter, r *http.Request, err error) {
	switch {
	case errors.Is(err, errRunning):
		httpx.WriteError(w, r, http.StatusConflict, httpx.CodeInstanceRunning, "stop the server before extracting an archive")
	case r.Context().Err() != nil:
		h.log.DebugContext(r.Context(), "state check ended with the request", "err", err)
	case errors.Is(err, agentapi.ErrDockerUnavailable):
		httpx.WriteError(w, r, http.StatusServiceUnavailable, httpx.CodeDockerUnavailable, "docker is not available on the host")
	default:
		httpx.WriteError(w, r, http.StatusServiceUnavailable, httpx.CodeAgentUnavailable, "the agent is not reachable")
	}
}

// ExtractRunning reports whether an extract job runs for the server. An unreachable service
// counts as "no job" (spec §5.1). It implements servers.ExtractGate.
func (h *Handler) ExtractRunning(ctx context.Context, serverID int64) bool {
	ctx, cancel := context.WithTimeout(ctx, gateTimeout)
	defer cancel()
	job, err := h.files.Job(ctx, serverID)
	return err == nil && job != nil && job.State == filesapi.JobRunning
}

import (

// fakeFiles simulates the mcpanel-files service: one flat map of file contents per server, a
// directory exists if a file lies below it; Extract starts a job that only finishJob ends.
type fakeFiles struct {
	mu    sync.Mutex
	files map[string][]byte // "<id>/<path>" -> content
	mtime int64
	job   *filesapi.Job
}

func newFakeFiles() *fakeFiles { return &fakeFiles{files: map[string][]byte{}, mtime: 1_760_184_000_000} }

func key(id int64, p string) string { return fmt.Sprintf("%d/%s", id, p) }

func (f *fakeFiles) finishJob() {
	f.mu.Lock()
	defer f.mu.Unlock()
	if f.job != nil {
		f.job.State = "done"
	}
}

func (f *fakeFiles) Health(context.Context) error { return nil }

func (f *fakeFiles) List(_ context.Context, id int64, dir string) (filesapi.ListResponse, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	prefix := key(id, "")
	if dir != "" {
		prefix = key(id, dir+"/")
	}
	seen := map[string]filesapi.Entry{}
	for k, b := range f.files {
		rest, ok := strings.CutPrefix(k, prefix)
		if !ok {
			continue
		}
		name, sub, isDir := strings.Cut(rest, "/")
		_ = sub
		if isDir {
			seen[name] = filesapi.Entry{Name: name, Type: filesapi.TypeDir, MTime: f.mtime}
		} else {
			seen[name] = filesapi.Entry{Name: name, Type: filesapi.TypeFile, Size: int64(len(b)), MTime: f.mtime}
		}
	}
	out := make([]filesapi.Entry, 0, len(seen))
	for _, e := range seen {
		out = append(out, e)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return filesapi.ListResponse{Entries: out}, nil
}

func (f *fakeFiles) Read(_ context.Context, id int64, p string) (filesapi.ReadResponse, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	b, ok := f.files[key(id, p)]
	if !ok {
		return filesapi.ReadResponse{}, filesapi.ErrNotFound
	}
	return filesapi.ReadResponse{Content: string(b), MTime: f.mtime, Size: int64(len(b))}, nil
}

func (f *fakeFiles) Write(_ context.Context, req filesapi.WriteRequest) (filesapi.WriteResponse, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	f.files[key(req.ID, req.Path)] = []byte(req.Content)
	f.mtime++
	return filesapi.WriteResponse{MTime: f.mtime, Size: int64(len(req.Content))}, nil
}

func (f *fakeFiles) Upload(_ context.Context, id int64, p string, _ bool, size int64, body io.Reader) (filesapi.UploadResponse, error) {
	b, err := io.ReadAll(body)
	if err != nil {
		return filesapi.UploadResponse{}, fmt.Errorf("%w: %w", filesapi.ErrUnavailable, err)
	}
	if int64(len(b)) != size {
		return filesapi.UploadResponse{}, filesapi.ErrInvalid
	}
	f.mu.Lock()
	defer f.mu.Unlock()
	f.files[key(id, p)] = b
	return filesapi.UploadResponse{Size: size}, nil
}

func (f *fakeFiles) Download(_ context.Context, id int64, p string) (filesapi.Download, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	b, ok := f.files[key(id, p)]
	if !ok {
		return filesapi.Download{}, filesapi.ErrNotFound
	}
	return filesapi.Download{Body: io.NopCloser(bytes.NewReader(b)), Size: int64(len(b)), Name: path.Base(p)}, nil
}

func (f *fakeFiles) Mkdir(context.Context, int64, string) error           { return nil }
func (f *fakeFiles) Rename(context.Context, filesapi.RenameRequest) error { return nil }
func (f *fakeFiles) Delete(context.Context, int64, string) error          { return nil }

func (f *fakeFiles) Extract(_ context.Context, req filesapi.ExtractRequest) (filesapi.Job, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	j := filesapi.Job{ID: "j1", State: "running", Path: req.Path, Dest: req.Dest}
	f.job = &j
	return j, nil
}

func (f *fakeFiles) Job(context.Context, int64) (*filesapi.Job, error) {
	f.mu.Lock()
	defer f.mu.Unlock()
	if f.job == nil {
		return nil, nil
	}
	j := *f.job
	return &j, nil
}
